# 실험 보드 Rev 5 — 꽂는 순서표 (wiring-EXP.json에서 자동 생성)

구멍 표기: a~j = 세로 글자, 숫자 = 행. T+/T− = 위쪽 전원 레일, B+/B− = 아래쪽 레일 (레일 번호는 레일 구멍 순서, 25와 26 사이 끊김).

## 1단계: 칩 (LM358, 반달 홈이 1행 쪽)

| 칩 핀 | 구멍 | 역할 |
|---|---|---|
| 1 | e10 | A 출력 = 사인파 |
| 2 | e11 | A − 입력 (1번과 연결) |
| 3 | e12 | A + 입력 (필터 출력) |
| 4 | e13 | GND |
| 5 | f13 | B + 입력 (기준 1.8 V) |
| 6 | f12 | B − 입력 (7번과 연결) |
| 7 | f11 | B 출력 = 가상 접지 |
| 8 | f10 | 5 V |
