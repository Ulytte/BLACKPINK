# 2조 실험 따라하기 (실험 보드 Rev 5)

> 이 문서 하나만 보고 순서대로 하면 된다. 수치 중 **(추정)** 은 시뮬레이션·계산 값이고 실측이 아니다.
> 시뮬·모의 실행으로 검증한 범위는 맨 아래 "검증 기록"에 있다. **실제 부품으로는 아직 아무도 안 해 봤다.** 0단계 점검을 꼭 거칠 것.

---

## 한눈에 보기

| 단계 | 할 일 | 시간 |
|---|---|---|
| 0 | 부품 확인 → 보드 조립 → 업로드 → 전원 점검 | 2~3시간 |
| 1 | 보정 저항으로 측정값 확인 | 20분 |
| 2 | 와셔 용기 누수 시험 (물 하루) | 하루 |
| 3 | 소금물 3농도 단조성 확인 | 30분 |
| 4 | 온도계수 α 측정 | 1시간 |
| 5 | 본 실험: W/C 6수준 × 독립 배합 3회 = 18배합 (하루 6배합 × 3일) | 하루 3~4시간 |
| 6 | `analyze.py` 로 분석 → 보고서 | 10분 |

**측정 방식:** 같은 시료를 **사인파(집게 E1·E4) → 사각파(집게 Q1·Q4)** 순서로 잰다. 회로는 브레드보드 한 장에 둘 다 꽂혀 있고, 집게 두 개만 옮기면 된다.

### 0-1b. 와셔 전극 용기 만들기
볼트·와셔·너트가 모두 스테인리스라서, **벽 바깥으로 나온 볼트 끝이 안쪽 M12 와셔(전극)와 전기적으로 이어져 있다.** 집게는 거기에 물린다.

```
 용기 안 (페이스트)            │벽│            용기 밖
 볼트머리 · M4 · M8 · M12(전극) │  │ M12 · M4 · 너트 ── 볼트 끝 ← 집게
```
준비물: PET 67×67×100 용기(예비 1개 더), SUS M4×40 렌치볼트 2, M4 너트 2, 평와셔 M4 ×4, M8 ×2, M12 ×4, 드릴(Ø4.5) 또는 달군 송곳, 유성펜. 고무 패킹(안지름 4~5)은 샐 때만.

1. 안쪽 바닥에서 **50 mm**에 충전선 긋기.
2. 마주 보는 두 벽의 **폭 중앙, 안쪽 바닥에서 25 mm**에 구멍 위치 표시 (±2~3 mm는 괜찮음).
3. Ø4.5 구멍 (작은 구멍에서 넓히거나 달군 송곳으로, 갈라지지 않게). 거스러미 정리.
4. 안쪽에서 **볼트 머리 → M4 → M8 → M12** 순서로 꿰어 넣기 (M12가 벽 안쪽 면에 닿게).
5. 바깥에서 **M12 → M4 → 너트**. 손으로 꽉 + 렌치로 살짝만 (세게 조이면 PET가 찌그러져 샘).
6. 반대쪽도 똑같이. 바깥에 **A**, **B** 표시.
7. 두 M12 와셔 면 사이 거리를 자로 재서 기록.
8. 연결 확인은 2단계 누수 시험 때 한다: 물을 채운 채 `s` → "전극 열림" 경고가 안 뜨면 볼트–와셔 연결 정상.
9. 누수 시험(2단계). 새면 벽과 M12 사이에 고무 패킹.

**집게 연결:** 바깥 볼트 끝(너트 바깥 나사산) 또는 너트에 악어클립. A → E1(사인)/Q1(사각), B → E4/Q4. 두 집게·볼트 끝이 서로 닿지 않게, 바깥 볼트와 벽 바깥면은 항상 마르게(젖은 벽으로 전류가 새면 값이 틀어짐). 집게선은 짧게 테이프로 고정, 볼트 끝은 측정 전에 닦기.
**한 번 만든 용기는 끝까지 그 하나만, 세척할 때도 볼트를 풀지 않는다.** 참고 도면: `최종도면/01_사인파_Rev4/configuration-4S.png`, `assembly-4S.png`.

## 펌웨어 명령 요약

| 명령 | 뜻 |
|---|---|
| `l W050-B1-M1` | 시료 이름 정하기 (**측정 전에 항상**) |
| `w` | 물 넣은 순간 (경과 시간 기록 시작) |
| `t` | 온도 (센서를 페이스트 가운데에 30초 넣은 뒤) |
| `s` | 사인파 측정 (집게 E1·E4) — 3회 반복 중앙값, 약 2초 |
| `q` | 사각파 측정 (집게 Q1·Q4) — 약 1초 |
| `ref s` / `ref q` | 지금 시료를 기준으로 저장 (5회 측정) |
| `sig 3.2` | LCD 판정에 쓸 σ (분석에서 구한 σ_배합을 넣기) |
| `alpha 0.020` | 온도계수 (4단계에서 구한 값) |
| `info` / `reset` | 설정 보기 / 초기화 |
| 버튼 짧게 / 1.5초 이상 | 마지막 모드로 측정 / 기준 저장 |

**이름 규칙 (분석기가 이 규칙으로 묶음):** `W050-B1-M1` = W/C 0.50, 배합 1번, 측정 회차 1 · `CAL-100` = 보정 저항(표시값) · `SALT-4` = 소금물 4 g/L · `ALPHA-15` = α 측정, 15 °C 단계

## 1단계. 보정 저항 (20분)
1. 키트 **100 Ω**: 집게 E1·E4 → `l CAL-100` → `t`(센서는 공기 중이어도 됨) → `s` → 집게를 Q1·Q4로 → `q`.
2. 키트 **1 kΩ**: `l CAL-1000` 으로 같은 방법.
3. 330 Ω 1% 여분이 있으면 `l CAL-330` 으로 한 번 더 (가장 정확한 확인).
4. 합격: 키트 저항은 ±6% 안, 330 Ω 1%는 ±2% 안. **사인과 사각이 같은 저항에서 2% 안으로 일치.** 어긋나면 집게 물림, RQ·R1 위치를 확인한다.

## 2단계. 와셔 용기 누수 시험 (하루)
- 와셔 용기에 물을 50 mm 선까지 채우고 하루 둔다. 새면 수도 고무 패킹(안지름 4~5)을 와셔 사이에 넣는다.
- **이 용기 하나만 끝까지 쓴다** (전극 간격이 달라지면 값이 바뀜).

## 3단계. 소금물 단조성 (30분)
- 정제수 300 ml에 소금 0.6 g / 1.2 g / 2.4 g (= 2, 4, 8 g/L) 세 병을 만든다.
- 각각 용기에 50 mm까지 → `l SALT-2` → `t` → `s` → 집게 옮겨 `q` → 다음 농도 (용기는 정제수로 헹구고 물기 제거).
- 합격: 농도↑ → Z↓ (분석 보고서 3절에서 자동 확인). 소금물 Z가 수백 Ω이면 페이스트와 같은 범위라 좋다 (추정).

## 4단계. 온도계수 α (1시간)
목표: 20 °C 보정에 쓸 α. **페이스트 대신 4 g/L 소금물**로 한다 (페이스트는 재는 동안 수화로 값이 변해서 온도 효과와 섞인다). 페이스트 α는 다를 수 있다는 점을 보고서에 적는다 (추정).
1. 소금물을 냉장고에서 약 10 °C로 식혀 용기에 50 mm까지 붓는다.
2. 용기를 미지근한 물(약 35 °C)이 담긴 큰 그릇에 담가 천천히 데운다.
3. 약 3 °C 오를 때마다: `l ALPHA-<온도>` (예: `l ALPHA-12`) → 저어서 섞기 → `t` → 센서 빼기 → `s` → 집게 옮겨 `q` → 센서 넣고 `t`.
4. 12 → 27 °C까지 6단계 이상.
5. `analyze.py` 보고서 1절의 α를 펌웨어에 `alpha 0.0xx` 로 넣는다.

## 5단계. 본 실험

### 5-1. 배합표 (시멘트 400 g 고정, 물만 바꿈)
| W/C | 시멘트 [g] | 물 [g] | 페이스트 부피 [ml] (추정, 비중 3.15) |
|---|---|---|---|
| 0.40 | 400 | 160 | 287 |
| 0.50 (기준) | 400 | 200 | 327 |
| 0.53 | 400 | 212 | 339 |
| 0.56 | 400 | 224 | 351 |
| 0.59 | 400 | 236 | 363 |
| 0.60 | 400 | 240 | 367 |

- 용기 50 mm 선까지 약 210 ml가 필요하다 (추정, 안쪽 약 65×65 mm). 모든 배합이 넉넉하다.
- 저울 1 g 단위 → 물 오차 ±0.5 g ≈ W/C ±0.001. 판정선 간격(약 0.016)보다 충분히 작다.
- 판정선 참고: 단위수량 +20 kg/m³ ≈ W/C 0.50 → 0.516 (페이스트 기준, 추정). 0.53은 판정선의 약 2배 간격이다.
- 시멘트 사용량: 18배합 × 400 g = 7.2 kg, 연습 1~2배합 포함 약 8 kg → **10 kg 한 포대(같은 로트)**.

### 5-2. 배합 순서 (블록 무작위, 바꾸지 말 것)
하루에 각 수준을 1번씩 하고 순서를 섞었다. 그래야 날짜·피로·실내 온도 효과가 W/C 효과와 섞이지 않는다.

| 날 | 순서 |
|---|---|
| 1일차 | W050-B1 → W056-B1 → W060-B1 → W040-B1 → W059-B1 → W053-B1 |
| 2일차 | W040-B2 → W053-B2 → W056-B2 → W050-B2 → W059-B2 → W060-B2 |
| 3일차 | W050-B3 → W056-B3 → W059-B3 → W060-B3 → W053-B3 → W040-B3 |

첫날은 실전 전에 **W/C 0.50 연습 배합 1회**를 해서 손에 익힌다 (이름 `PRACTICE`, 분석에서 빠짐).

### 5-3. 전날 준비
- 시멘트, 정제수, 용기, 도구를 **실험실에 하룻밤 두기** → 재료 온도를 실온으로 맞춘다 (ΔT ≤ 1 °C 목표).
- 안전: **니트릴 장갑, 보안경, 가루 계량할 때 마스크.** 시멘트는 강알칼리다. 피부에 묻으면 바로 물로 씻는다.

- 매번 펌웨어 LCD에 `OK/ABN` 이 보인다. 이건 **보조 표시**이고, 공식 판정은 6단계 분석으로 한다.

### 5-5. 폐기
- **싱크대에 버리지 않는다.** 남은 페이스트는 봉지째 굳혀 일반 쓰레기로 버린다.
- 헹군 물은 양동이에 모아 하루 가라앉히고, 윗물만 버린 뒤 바닥 찌꺼기는 굳혀서 버린다.

## 6단계. 분석
```bash
python 03_PC/analyze.py
```
`03_PC/result/report.md` 와 그림 `fig_wc.png`, `fig_alpha.png` 가 생긴다. 보고서에서 볼 것:
1. **σ 세 가지를 구분한다:** 기기 반복성(같은 측정 안), 시료 반복성(재혼합 회차 간), **σ_배합(독립 배합 간 — 판정에 쓰는 σ)**
2. 기준 0.50 대비 각 수준의 Δ, d = Δ/σ_배합, **|Δ| ≥ 3σ_배합 이면 "구별됨"**
3. ANOVA p값, 단조성
4. **검출 가능한 최소 W/C 변화 = 3σ_배합 / 감도** → 판정선 0.016과 비교. 이게 프로젝트 질문("판정선 수준을 구별할 수 있나")의 답이다
5. 사인 대 사각: |감도|/σ_배합 이 큰 쪽. 20% 안으로 비슷하면 규칙대로 간단한 사각파

결과가 "구별 못 함"이어도 **근거 있는 결과**다. 그대로 보고하고, 무엇이 σ를 키웠는지(온도, 수화 드리프트, 배합 손 오차)를 보고서 숫자로 설명한다.

`sig` 명령: 분석에서 나온 σ_배합을 `sig 3.2` 처럼 넣으면, 이후 LCD 판정이 같은 기준으로 표시된다 (시연용).
